# 构建说明：鸿蒙电脑平板混合版

## 环境要求

- DevEco Studio 5.0+（推荐最新）
- HarmonyOS NEXT SDK（API 12+，鸿蒙 7.0 用 API 14/15）
- Node.js 18+（DevEco 自带）
- 鸿蒙 PC 或平板（USB 调试模式）或模拟器

## 打开工程

1. 打开 DevEco Studio → File → Open → 选 `harmony-hybrid/` 文件夹。
2. 等待 ohpm 安装依赖、同步 hvigor。

## 配置 CodeCoreAgent 地址

编辑 `entry/src/main/ets/pages/Index.ets`：

```typescript
const DEFAULT_URL = 'http://192.168.1.100:8765'  // 改成你跑 CodeCoreAgent 的机器
```

或装好后在 App「设置」页改，会存到 Preferences。

## 编译安装

1. 连接鸿蒙 PC / 平板（USB + hdc），或启动模拟器。
2. 点 Run（或 `Ctrl+F5`）。
3. DevEco 自动编译 → 签名（调试）→ 安装 → 启动。

## 生成 .hap

1. Build → Build Hap(s)/APP(s) → Build Hap(s)。
2. 产物在 `harmony-hybrid/entry/build/default/outputs/default/`。
3. 正式发布需在 `build-profile.json5` 配置签名证书。

## 适配要点

- 双端兼容：`deviceTypes` 含 `tablet` + `2in1`，一个 HAP 同时装平板和鸿蒙电脑。
- 布局断点：窗口宽 ≥ 1024vp 走电脑布局，否则走平板布局。窗口 API 返回的
  是 px，`Index.ets` 里已按屏幕密度换算成 vp 再判断，高分屏平板不会被误判。
- PC 多窗口：`module.json5` 已设 `supportWindowMode` 全支持。
- 平板触控：Web 组件默认支持手势返回；浮动按钮半透明。
- 键鼠：PC 上 Web 组件自动支持 hover/右键。
- 深色模式：`resources/dark/element/color.json` 已配深色值。
