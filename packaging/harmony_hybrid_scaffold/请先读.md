# CodeCoreAgent 鸿蒙电脑平板混合版（v0.81.0）

## 这是什么

一个 **ArkTS 壳工程脚手架**，用 HarmonyOS NEXT 的 `Web` 组件加载 CodeCoreAgent
的 Web UI，适配鸿蒙 PC（MateBook 等）与平板（MatePad 等）。

**不是** 已签名的 `.hap`。需要在 **DevEco Studio** 里打开、编译、签名后安装。

## 目录

| 路径 | 作用 |

## 快速开始

1. 装 **DevEco Studio**（带 HarmonyOS NEXT SDK 5.0+/6.0/7.0）。
2. 用 DevEco 打开 `harmony-hybrid/` 文件夹。
3. 改 `entry/src/main/ets/pages/Index.ets` 顶部的默认 URL，指向你跑起来的
   CodeCoreAgent 桌面版地址（本机或局域网），默认 `http://127.0.0.1:8765`。
4. 连鸿蒙 PC 或平板（USB / Wi-Fi 调试），点 Run 编译安装。
5. App 内「设置」页可改 URL，自动存 Preferences，下次启动记住。

## 平板与电脑互通兼容

**一套代码、一个 HAP，同时跑鸿蒙平板（MatePad 等）和鸿蒙电脑（2in1 / MateBook 等）**：

- `module.json5` 的 `deviceTypes` 已含 `tablet` + `2in1`，安装不限设备形态。
- **鸿蒙电脑**（窗口宽 ≥ 1024vp）：左侧窄工具栏 + 右侧 Web 内容区，支持键鼠、
  多窗口与自由窗口（`supportWindowMode` 已全开）。
- **平板**（窗口宽 < 1024vp）：Web 全屏 + 半透明浮动返回/设置按钮，触控优化。
- 窗口拉伸、折叠展开、外接显示器时按窗口宽度实时切换布局
  （按 vp 判断，代码内已做 px → vp 换算，与屏幕分辨率无关）。
- **互通**：平板和电脑连的是同一个 CodeCoreAgent 桌面后端（局域网 URL），
  会话、技能、MCP 配置都存在后端，两端打开就是同一份数据，天然互通。

## 注意

- CodeCoreAgent 桌面版需先在 Mac/Windows/Linux 上跑起来，并开启远程访问
  （`codeagent desktop --host 0.0.0.0 --port 8765`），鸿蒙设备通过局域网访问。
- 本脚手架不包含签名证书；调试签名在 DevEco 里自动生成，正式发布需申请。
