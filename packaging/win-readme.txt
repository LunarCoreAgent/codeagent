codeagent desktop for Windows

Install: run codeagent-desktop-windows-amd64-setup.exe
First launch: Settings → pick a provider and paste an API key.
Local models: install Ollama, then `ollama pull qwen2.5-coder:7b`, provider = ollama.

Uninstall: Settings → Apps → codeagent, or the uninstaller in the install folder.
Projects and chats stay in %USERPROFILE%\.codeagent and %USERPROFILE%\codeagent-projects.
