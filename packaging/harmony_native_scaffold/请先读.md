# CodeCoreAgent 纯鸿蒙版（v0.90.3）

## 这是什么

纯 **ArkTS / ArkUI** 鸿蒙应用。按窗口宽度自适应。

**应用市场分发设备：** `module.json5` 的 `deviceTypes` 为 **`tablet` + `2in1`（鸿蒙平板与鸿蒙电脑）**。  
**不分发手机**（直板机 / 折叠屏手机不在分发范围）。若误装到手机，会提示「仅支持平板与鸿蒙电脑」。

AGC 应用分发设备请勾选：**平板、2in1**，不要勾选手机。云测请覆盖平板与 2in1，与声明一致。

## 功能策略

| 场景 | 行为 |
|------|------|
| **鸿蒙平板** | 完整功能可用（对话、模型、导演台、项目、技能、自动化等）。 |
| **鸿蒙电脑（2in1）** | 完整功能可用。 |
| **手机** | 不分发；若安装则整页提示不可用。 |
| **Mac / Windows / Linux 桌面版** | 完整 Agent 工具链与调度宿主（无华为账号实名门闩）。 |

## 应用市场上架：实名核验（仅鸿蒙包）

按《审核指南》第 12 章，本包在提供**合成生成内容（对话）**前须核验真实身份：华为账号登录（`LoginWithHuaweiID`），取得 OpenID 即通过。不申请一键登录权限。

## 快速开始

1. DevEco 打开 `harmony-native/`，在 **平板或鸿蒙电脑** 上签名安装。
2. 完成华为账号实名核验后配置模型即可对话。
