# CodeCoreAgent 纯鸿蒙版（v0.81.0）

## 这是什么

纯 **ArkTS / ArkUI** 鸿蒙应用：**平板与鸿蒙电脑（2in1）共用同一套 HAP**。
按窗口宽度（≥1024vp 为电脑布局）自适应，功能入口全部保留。

## 功能策略

| 场景 | 行为 |
|------|------|
| **鸿蒙平板** | 对话、模型、记忆、知识库、浏览器、偏好等可直接使用。导演台 / 指挥中心 / 技能库 / 自动化等依赖桌面宿主的功能**保留入口**，并提示「请在桌面版使用」。 |
| **鸿蒙电脑** | 同一功能面完整展示；本机 bash / 文件写 / Comfy 等仍建议配合 Mac/Win/Linux **CodeCoreAgent 桌面版**。 |
| **桌面版** | 完整 Agent 工具链与调度宿主。 |

## 已保留功能面

总览 · 对话 · 浏览器 · 导演台 · 指挥中心 · 长期记忆 · 知识库 · 技能库 · 模型管理 · 自动化 · 日志 · 版本说明 · 隐私条款 · 偏好设置

## 快速开始

1. DevEco 打开 `harmony-native/`，签名安装。
2. 配置模型后即可对话；平板上看到「桌面版」角标时，到桌面端完成对应能力。
