# 构建说明：纯鸿蒙版

## 环境

- DevEco Studio 5.0+，HarmonyOS NEXT SDK（API 12+）
- 鸿蒙 PC / 平板 / 模拟器

## 打开

DevEco → File → Open → `harmony-native/`，等 ohpm 同步。

## 编译安装

1. 连设备或启动模拟器。
2. 点 Run（`Ctrl+F5`）。
3. 首次启动进「设置」页填 API 地址与 Key。

## 生成 .hap

Build → Build Hap(s) → 产物在 `entry/build/default/outputs/default/`。
正式发布需在 `build-profile.json5` 配签名证书。

## 网络权限

`module.json5` 已声明 `ohos.permission.INTERNET`。
真机首次运行时系统会弹联网授权，允许即可。

## 平板与电脑数据互通（可选）

配置（`Config.ets`）与会话（`ChatStore.ets`）默认存本机 Preferences，平板和
电脑互不相同。要让两端自动同步，用 HarmonyOS 分布式数据对象
（`@kit.ArkData` 的 `distributedDataObject`）包一层：

1. `module.json5` 的 `requestPermissions` 加
   `ohos.permission.DISTRIBUTED_DATASYNC`（受限权限，正式上架需在
   AppGallery Connect 申请）。
2. 平板和电脑登录**同一华为账号**并处于同一局域网（或开蓝牙），系统会自动
   组成可信设备组。
3. 启动时创建分布式对象，字段变更自动在两端对传：

```typescript
import { distributedDataObject } from '@kit.ArkData';

// 示意：两端用相同 sessionId 即可组网同步（API 细节以所装 SDK 官方文档为准）
const syncObj = distributedDataObject.create(this.ctx, { configJson: '' });
syncObj.setSessionId('cca-sync');

// 对端改了配置：落本地 Preferences 并刷新界面
syncObj.on('change', (sessionId: string, fields: Array<string>) => {
  const json = syncObj['configJson'] as string;
  // 解析 json → saveConfig(this.ctx, cfg) → this.cfg = loadConfig(this.ctx)
});

// 本端保存配置后调用，'local' 表示保存到可信组内所有设备
syncObj['configJson'] = JSON.stringify(this.cfg);
syncObj.save(this.ctx, 'local');
```

会话记录同理，把 `ChatStore` 的写操作同步成 JSON 字段即可；数据量大时建议
每个会话一个字段，或改用 `distributedKVStore`。

不想走分布式，也可以做「导出/导入 JSON」（`@kit.CoreFileKit` 调系统分享）。

## 扩展方向

- MCP 客户端：用 `@kit.NetworkKit` WebSocket 连 MCP server
- 工具调用：解析 LLM 返回的 tool_calls，本地执行
- 文件读写：`@kit.FileKit` 接入项目文件夹
- 知识库：`@kit.ArkData` relationalStore 存 wiki 页
- 双端同步：见上文「平板与电脑数据互通（可选）」
