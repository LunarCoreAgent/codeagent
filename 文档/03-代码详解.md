# CodeCoreAgent 代码详解

本文对照 **当前仓库源码** 说明模块职责与改动入口。包根：`src/codeagent/`。版本 0.26.0。

---

## 1. 工程布局

```
.
├── pyproject.toml              # 包名 codeagent、依赖 extras、入口 codeagent=cli.main:app
├── src/codeagent/              # 唯一业务包
├── tests/                      # pytest
├── packaging/                  # 图标、PyInstaller spec、Inno
├── scripts/                    # 桌面/CLI 打包
├── .github/workflows/          # ci.yml / binaries.yml / release.yml
├── 文档/                       # 项目书、操作说明、本文
├── README.md / LICENSE / PRIVACY.md / CHANGELOG.md
└── 项目说明.md
```

`hatchling` 只打包 `src/codeagent`。桌面 HTML **不在独立前端仓库**，而在 `desktop/ui.py` 的字符串 `HTML` 里。

## 2. 启动链路

### 2.1 CLI

`src/codeagent/cli/main.py` 定义 Typer 应用：

| 命令 | 作用 |
|---|---|
| `run` | 单任务跑完 Agent |
| `chat` | 交互多轮 |
| `lead` | 领导模式 |
| `desktop` | `run_desktop()` |
| `settings` | 显示/设置/清空个性化 |
| `version` / `changelog` / `logs` | 版本与日志 |

`desktop` 懒加载 `codeagent.desktop`，未装 `pywebview` 时给出安装提示。

### 2.2 桌面窗口

`src/codeagent/desktop/app.py`：

1. `DesktopAPI(root=...)` 作为 JS 桥。  
2. `_themed_html()` 把 `MARK_URI` 填进 `__BRAND_MARK_SRC__`，并按已存主题给 `<body>` 加 `light`。  
3. `webview.create_window(..., js_api=api)`，阻塞到关窗。  
4. 冻结包遇到 `--version` 只打印 `CodeCoreAgent vX` 后退出（CI 冒烟）。

品牌常量：`desktop/brand.py`（`APP_NAME`）。侧栏图：`desktop/brand_mark.py`（`make_icon.py` 生成的 data URI）。

## 3. 核心循环 `core/`

### 3.1 `Agent`（`core/agent.py`）

`run(task)` 大致：

1. 把用户消息写入历史。  
2. 循环直到模型不再要工具或触及 `max_iterations`。  
3. 每次 `provider.complete(...)`，解析 `ToolCall`。  
4. `PermissionPolicy` 决定批准 / 拒绝。  
5. `ToolRegistry` 执行，结果以 `ToolResult` 回灌。  
6. 通过 `on_event` 向外抛 `text` / `tool_call` / `tool_result` / `done` / `error` 等。

默认系统提示要求：先读再改、不编造文件内容、结束后短总结。

相关类型在 `core/types.py`：`Message`、`Role`、`LLMResponse`、`Usage`。配置在 `core/config.py`。预算在 `core/budget.py`（超限 `BudgetExceededError`）。

### 3.2 改 Agent 行为的入口

- 换模型：换 `provider`。  
- 换工具：换 `tools` 注册表。  
- 换审批：换 `permissions`。  
- 个性化：`settings` 拼进 system。  
- 桌面还会把进化补丁、思考强度写入 `instructions`（见 `DesktopAPI._settings_with_patches`）。

## 4. 模型层 `llm/`

| 文件 | 职责 |
|---|---|
| `base.py` | `LLMProvider` 抽象：`complete(...)` |
| `anthropic.py` / `openai.py` / `ollama.py` | 各后端 |
| `registry.py` | `create_provider` / `list_providers` / `register_provider` |
| `aggregate.py` | `parse_provider_spec("a,b")`、`AggregateProvider`（fallback / round-robin） |
| `presets.py` | 网关与本地预设 |

桌面不直接 new Provider，而是：

- `models.ModelAssets.active`：`local:模型@端点id` / `api:{id}` / `mix:{id}` / `route:free` / 空（同自由路由）  
- `build_active_provider(assets)` 解析后构造后端。

局域网探测：Ollama `GET /api/tags`，失败再试 OpenAI `GET /v1/models`，Gradio 看 `/config`。实现见 `desktop/models.py` 与探测辅助函数。

## 5. 工具 `tools/` 与安全 `security/`

`tools/base.py`：`Tool`（name、description、parameters、risk、`run`）与 `ToolRegistry`。

`default_tools(root_dir)` 注册文件系统 + 搜索 + Shell。工作区外路径应被拒绝。

`security/policy.py`：`RiskLevel`、`PermissionPolicy`（permissive / 按级确认 / 关闭）、`classify_command`。CLI 用交互 `Prompt`；桌面用 `permissions.py` 的确认队列，前端弹窗后 `resolve_confirm`。

---

## 6. 桌面桥 `desktop/api.py`（最厚的一层）

`DesktopAPI` 的方法名即 `pywebview.api.xxx`。前端 `ui.py` 里直接调用。

分类记忆：

| 前缀/方法 | 职责 |
|---|---|
| `get_state` / `save_config` / `save_settings` | 主题、个性化、默认 provider |
| `send` / `stop` | 对话；Gradio 时走 `_run_video_gen` |
| `get_model_assets` / `set_active_model` | 选择器数据；空与 `route:free` 规范成自由路由 |
| `get_models_page` / `add_endpoint` / `add_api_model` / `save_mixture` | 模型管理 |
| `add_route_rule` / `route_sandbox` / `_provider_for_message` | 自由路由 |
| 项目 / 对话 CRUD | `projects.py` |
| `pick_attachments` | 系统文件框 → 项目 `files/` |
| 知识库 / 视频运营 / 权限 / 进化 / cron | 各 store |

**自由路由实现要点**（`desktop/router.py` + api）：

- `FREE_ROUTE_REF = "route:free"`，`is_free_route(ref)` 把 `""` 也当成自由路由。  
- `_provider_for_message`：若 **不是** 自由路由，策略改成「默认直连」，不改 `assets.active`。  
- 若是自由路由：按优先级匹配关键词，否则兜底规则，临时把 `active` 设为目标再 `build_active_provider`。

**设置页滚动**：`ui.py` 中 `#main` 设 `min-height:0; overflow:hidden`，`.page-body` 与 `#sidebar` 设 `overflow-y:auto; min-height:0`，避免内容把布局撑出视口却无法滚动。

## 7. 前端 `desktop/ui.py`

单文件：`<style>` + 各 `<section class="page" id="page-...">` + JS。

- 导航：`go(page)` 切换 `.active`，设置类页面会 `setSettingsOpen(true)`。  
- `renderPicker`：第一项自由路由，再聚合池、本地、API。  
- `pickModel` → `set_active_model`。  
- `send()` 读输入框、附件、视频参数。  
- 事件：`window._onEvent` 接收 Python `push` 的 kind（status / text / tool / done / stopped）。

改 UI 只需改此文件；打包后须重新 `build_desktop.py`，源码改动不会自动进已安装的 `.app`。

## 9. 打包代码路径

1. `packaging/make_icon.py`：读 `logo-art.png` → `icon.png` / `.icns` / `.ico` / `mark.png`，并写 `brand_mark.py`。  
2. `scripts/build_desktop.py`：PyInstaller 使用 `packaging/codeagent-desktop.spec`。  
   - Darwin：`CodeCoreAgent.app` + `hdiutil` → `dist/codeagent-desktop-macos-<arch>.dmg`  
   - Windows：`codeagent.exe` → zip；若有 `ISCC.exe` 再跑 `windows-setup.iss` → `*-setup.exe`  
3. `packaging/entry_desktop.py`：冻结入口，调 `run_desktop`。  
4. CI：`.github/workflows/binaries.yml` 矩阵三平台，tag `v*` 上传 Release。

改 logo：只改 `logo-art.png`，再跑 `make_icon.py`，然后重新打包。

## 10. 测试怎么对应功能

`tests/test_desktop.py` 用假 window 调 `DesktopAPI`：

- 模型资产、端点、聚合池  
- 自由路由：`test_chat_routes_through_rule`、`test_set_active_free_route`、`test_pinned_model_skips_free_route`  
- UI 字符串：`test_ui_has_all_pages_and_bridge`、`test_ui_chat_composer_features`（含 `route:free`、滚动相关 CSS）  
- Gradio 不能当 chat provider、`send` 视频参数无 Gradio 时仍走聊天  

改选择器或路由时，优先跑上述用例。

## 11. 常见改动地图

| 你想改 | 先看 |
|---|---|
| 对话页按钮/布局 | `desktop/ui.py` 对话 section + CSS |
| 新桌面 API | `desktop/api.py` 加方法，JS 里 `pywebview.api.` |
| 新工具 | `tools/` 新类，在 `default_tools` 注册 |
| 新模型厂商 | `llm/` + `registry.register_provider` |
| 路由关键词 | `desktop/router.py` 的 `BUILTIN_TASK_TYPES` 或规则 JSON |
| 版本号 | `pyproject.toml`、`__init__.py`、`releases.py`、spec/iss |
| 权限默认值 | `desktop/permissions.py` |
