# CodeCoreAgent 功能总览（对照源码 0.36.0）

产品名 **CodeCoreAgent**（CCA）。Python 包与 CLI 仍叫 `codeagent`。  
本文按「用户能做什么 → 对应源码」说明全部功能，版本以 `pyproject.toml` / `src/codeagent/releases.py` 为准。

---

## 0. 三层入口

| 入口 | 怎么启动 | 源码 |
|---|---|---|
| Python 库 | `from codeagent import Agent` | `src/codeagent/__init__.py` 导出公有 API |
| 命令行 | `codeagent <命令>` | `src/codeagent/cli/main.py`（Typer） |
| 桌面窗口 | `codeagent desktop` 或安装包 | `src/codeagent/desktop/app.py` → `ui.py` + `api.py` |

配置与用户数据默认只落在本机 `~/.codeagent/`，不经过项目方服务器。

---

## 1. Agent 主循环

**功能**：把用户任务交给大模型，模型可反复调用工具，直到给出最终文字或触及上限。

**入口**：`Agent.run(task)`（`core/agent.py`）

流程：

1. 写入用户消息；按需注入个性化、技能索引、记忆、预算状态。  
2. 调用 `LLMProvider.complete(...)`。  
3. 若返回 `ToolCall`：`PermissionPolicy` 审批 → `ToolRegistry` 执行 → `ToolResult` 回灌。  
4. 通过 `on_event` 向外抛 `text` / `tool_call` / `tool_result` / `approval` / `done` / `error` / `skills_activated`。  
5. 超 `max_iterations` 抛 `MaxIterationsError`；超 token 抛 `BudgetExceededError`。

默认系统提示要求：先读再改、不编造文件内容、改完尽量验证、结束短总结。

---

## 2. 模型接入

统一抽象：`LLMProvider.complete(messages, tools=None, system=None)`。

| 路线 | Provider 名 | 说明 |
|---|---|---|
| 云端 | `anthropic` `openai` | 官方或任意 OpenAI 兼容 Base URL |
| 本地 | `ollama` `lmstudio` `vllm` `llamacpp` | 免 key |
| 网关 | `openrouter` `siliconflow` `aihubmix` `oneapi` | 一把 key 调多模型 |
| 聚合 | `ollama,openrouter` | `AggregateProvider`：fallback 或 round-robin |

工厂：`create_provider()` / `parse_provider_spec()`（`llm/registry.py`、`llm/aggregate.py`）。  
桌面侧资产在 `desktop/models.py`：本地端点、API 模型、聚合池；探测 Ollama `/api/tags`、OpenAI `/v1/models`、Gradio `/config`、ComfyUI `:8188`。

通义等云端 500 / `InternalError.Algo`：中文提示并自动重试；自由路由失败后改走聚合池。

## 3. 内置工具

`default_tools(root)` 默认注册（`tools/__init__.py`）：

| 工具 | 类 | 风险 | 作用 |
|---|---|---|---|
| `read_file` | `ReadFileTool` | 只读 | 读工作区内文件 |
| `write_file` | `WriteFileTool` | 写入 | 新建/覆盖文件 |
| `edit_file` | `EditFileTool` | 写入 | 按旧/新字符串替换 |
| `list_dir` | `ListDirTool` | 只读 | 列目录 |
| `grep` | `GrepTool` | 只读 | 正则搜内容 |
| `glob` | `GlobTool` | 只读 | 按文件名模式匹配 |
| `bash` | `BashTool` | 按命令分类 | 跑 Shell；`classify_command` 自动分级 |
| `browser` | `BrowserTool` | 执行 | 开页/点击/填表（BrowserSkill / ego-lite） |
| `comfy` | `ComfyTool` | 执行 | 向本机 ComfyUI queue 工作流 |

可选再注册：

- `web_fetch` / `web_scrape`（Scrapling）  
- `ocr`（tesseract / EasyOCR）  
- `delegate`（子 Agent）  
- `ask_external_agent`（本机 Claude Code / Codex 等）  
- `memory_*`、`knowledge_*`、`video_*`、`use_skill`

路径逃逸：文件系统工具可限制在 `root_dir` 内。

## 4. 权限与安全

`security/policy.py`：

- 等级：`READ_ONLY` → `WRITE` → `EXECUTE` → `DESTRUCTIVE`  
- 策略：`permissive` / 按级确认 / `strict`（只读以外一律拒绝）  
- 桌面：`desktop/permissions.py` 五能力矩阵四级（完全自主 / 执行前确认 / 只读 / 关闭），确认弹窗超时拒绝，审计 JSONL

CLI 默认交互确认；`--yes` 全放行。被拒的调用作为错误回传，Agent 换路继续。

## 5. 记忆、技能、个性化

| 能力 | 功能 | 源码 |
|---|---|---|
| 短期记忆 | 历史超阈值则 LLM 总结旧轮 | `memory/compact.py` |
| 长期记忆 | 按项目 `memory.json`；对话/思考/进度自动写入；先注入最近 5 条对话；知识库开启时备份到 `raw/conversations/` | `memory/store.py` + `memory/journal.py` + `desktop/api.py` |

| 融合技能 | Impeccable / Taste / 女娲 / 论文脊柱 / CPython / Anime.js / BrowserSkill / 语音面等写入本体 | `skills/fusion.py` |

| 自进化 | 任务后反思写成新 SKILL.md | `skills/evolve.py` |
| 个性化 | 称呼/语言/说明/机器上下文注入全部对话 | `settings.py` |

## 6. 编排：三省六部 / 蓝图 / 领导

**三省六部** `court/`：中书规划 → 门下封驳（可打回）→ 尚书派六部并行 → 回奏。状态机非法跳转直接拒绝。审计 JSONL。

**蓝图 DAG** `blueprint/`：十种节点（agent / slot / manager / condition / approval / aggregate / join / loop / while / command）。同层并行，YAML 未知字段报错，运行评分卡。

**领导模式** `leader/`：一个领导拆任务，多名工人（可不同模型）按依赖分批并行。工人可 `ask_external_agent`；失败可升级本机 harness。运行存档 `~/.codeagent/runs/`。

## 7. 桌面版页面（用户可见功能）

窗口：`pywebview`，整页 HTML 在 `desktop/ui.py`，桥在 `desktop/api.py`。

| 页面 | 功能 |
|---|---|
| 总览 | 版本、当前模型、技能/记忆/运行数、外部平台、快捷入口 |
| 对话 | 项目、模型下拉（自由路由 / 钉死模型 / Gradio 视频）、停止生成、附件、思考强度、赞踩 |
| 导演台 | 企划 → 分镜 → Comfy/WAN/Hailuo 生成 → ffmpeg 合成 → 发布草稿 |
| 指挥中心 | 领导模式：下命令、进度板、历史运行、失败重试 |
| 记忆 | 增删改搜长期记忆，标来源（手动/对话/合并） |
| 技能 | 融合 / 视频 / 本分页；可浏览 SKILL.md |
| 知识库 | Obsidian/llmwiki 结构一键布置、检索、写入 inbox |
| 视频运营 | 选题 / 生成 / 剪辑 / 分析 / 多平台发布草稿（人工点发布） |
| 自动化 | 步骤链串行，上步产出当下步上下文 |
| 定时 | 五字段 cron；夜间进化作业可暂停不可删 |
| 自我学习 | 赞踩计入准确率，回流路由权重 |
| 进化 | 五角色作业；行为补丁 L0 自动生效、L2 待批；可回滚 |
| 日志 | 读 `~/.codeagent/logs/` |
| 模型管理 | 聚合池 / 本地端点 / API 模型；探测、测试、拉取、启停 |
| 自由路由 | 关键词规则 + 沙盒预览 + 成本/质量/本地权重 |
| 权限 | 能力矩阵 + 确认弹窗 + 审计 |
| 版本 | `releases.py` 全文 |
| 隐私 | 首次须同意；可再读 |
| 偏好 | 主题、称呼、语言、语音（嗲音/晓晨）、工人名册 |

对话模型第一项 **自由路由**（`route:free`）：按规则分发。选中某个模型则钉死，规则不改道。选中 Gradio 文生视频后才出现分辨率/帧数/推理步数。

## 8. 语音、小智、评测、自我调试

- **语音**：情绪标签 `[emotion:xxx]` → edge-tts 音色；可选本机 Whisper 麦克风。桌面可开嗲音/晓晨，播报先去掉 markdown。  
- **小智**：虚拟设备协议连 xiaozhi.me（OTA 激活 + Opus）。  
- **评测**：MBPP pass@1（会执行生成代码，须沙箱）。  
- **自我调试**：生成 → 跑验证 → 橡皮鸭解释 → 最小修复。
