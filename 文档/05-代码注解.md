## 2. 桌面桥（改功能时先看这里）

`DesktopAPI` 给 `pywebview` 的 `js_api`。页面用 `pywebview.api.方法()`。

导演台一组（保存企划不要走 `get_studio` 的 Comfy 探测，以免每次等 4 秒）：

- `get_studio` — 桌面快照 + 可选 probe_comfy
- `save_studio` / `studio_import_script` / `studio_add_shot` / `studio_remove_shot`
- `studio_generate_shot` — 后台线程 + `_push("studio", ...)`
- `studio_assemble` / `studio_interrupt`

事件：`window._onEvent`，`kind==='studio'` 时刷新导演台。

## 4. 打包链路

1. `packaging/codeagent-desktop.spec` — onedir `.app`，版本在 `CFBundleShortVersionString`
2. `scripts/build_desktop.py` — PyInstaller → 冒烟 `--version` → DMG（含 Applications 符号链接）
3. `packaging/windows-setup.iss` — 仅 Windows + Inno Setup
4. Mac 上的 `CodeCoreAgent-*-Windows打包.zip` 是**生成包**，不是 exe

改版本必须同步：`pyproject.toml`、`__init__.py`、`releases.py`、`CHANGELOG.md`、`uv.lock`、spec、iss。
