## 1. 项目背景

开发者需要一个能真正碰工作区的编码 Agent：读文件、改代码、跑命令、搜仓库，并能在多家模型之间切换。现有方案要么绑死单一云厂商，要么只有命令行、没有可安装的桌面壳。

本项目同时提供三层入口：

1. **Python 库**：嵌入自己的脚本与流水线。  
2. **命令行**：`codeagent run` / `chat` / `lead`。  
3. **桌面版**：pywebview 原生窗口，侧栏多页，可打成 macOS DMG 与 Windows 安装包。

设计原则是：**模型可换、工具可扩、权限默认可确认、数据留在本机**。

---

## 2. 目标与非目标

### 2.1 目标

- 用统一 `LLMProvider` 接云端 API、本地推理、聚合网关。  
- 完整 Agent 循环：历史 → 工具调用 → 回传 → 迭代上限与 token 预算。  
- 内置编码工具：读写改文件、列目录、grep/glob、Shell。  
- 工具按风险分级，写/执行默认需批准。  
- 桌面完成日常使用：对话、项目、模型、路由、权限、知识库、视频运营。  
- 本机可打包，不强制用户先装 Python（安装包路径）。

### 2.2 非目标

- 不做云端多租户 SaaS，不把对话默认上传到项目方服务器。  
- 不在 macOS 上交叉编译 Windows `.exe`（须在 Windows 或 GitHub Actions 上打）。  
- 重量级可选能力（Whisper、Playwright、EasyOCR）不打进默认安装包体积。

## 4. 功能范围（按子系统）

### 4.1 模型接入

- 云：Anthropic Claude、OpenAI 及任意 OpenAI 兼容 Base URL。  
- 本地：Ollama、LM Studio、vLLM、llama.cpp。  
- 网关：OpenRouter、硅基流动、AiHubMix、One-API / New-API。  
- 聚合：`--provider ollama,openrouter`，策略 fallback 或 round-robin。  
- 桌面资产：本地端点、API 模型、聚合池；局域网双协议探测（`/api/tags` 与 `/v1/models`）。

### 4.2 Agent 与工具

- 默认系统提示：先探索再改、用工具读真实文件、改完尽量验证。  
- 工具：`ReadFile` / `WriteFile` / `EditFile` / `ListDir` / `Grep` / `Glob` / `Bash`；可选 OCR、网页抓取、子 Agent 委派。  
- MCP：按配置加载外部 server 工具。  
- 预算：token 上限；子 Agent 用量记入根预算。  
- 自我调试：生成 → 执行反馈 → 解释 → 最小修复。

### 4.3 编排与协作

- **领导模式**：一个领导拆任务，多名工人并行，进度板与本地存档。  
- **外部增援**：发现本机 CLI harness（Claude Code、Codex、Gemini、cursor-agent、opencode）。  
- **三省六部**（`court/`）：规划 → 封驳 → 执行。  
- **蓝图 DAG**（`blueprint/`）：条件、审批门、join、loop/while、YAML 加载。

### 4.4 记忆、技能、个性化

- 短期：对话过长自动压缩。  
- 长期：本机记忆存储与检索；mem0 式事实对账。  
- 技能：兼容社区 `SKILL.md`；任务后可蒸馏新技能。  
- 个性化：称呼、语言、说明、主机上下文，注入本机所有对话。

### 4.5 桌面产品能力（当前）

| 页面 | 作用 |
|---|---|
| 总览 | 版本、模型、技能/记忆、外部平台 |
| 对话 | 多轮聊天、停止、附件、思考强度、页眉选模型 |
| 指挥中心 | 领导派遣与进度 |
| 项目 | 项目与对话归档 |
| 记忆 / 知识库 / 技能 | 本机知识与技能包 |
| 视频运营 | 选题、生成、剪辑、分析；Gradio WAN |
| 模型管理 | 端点、API、聚合池 |
| 自由路由 | 关键词规则、沙盒、权重 |
| 权限 / 日志 / 版本 / 隐私 | 能力开关、审计、条款 |
| 自动化 / 定时 / 学习 / 进化 | 工作流与自进化 |
| 偏好设置 | 主题、默认链路、语音、工人名册 |

对话模型下拉第一项为 **自由路由**（`route:free`）：按规则分发。钉死具体模型时规则不改道。选中 Gradio 文生视频后才出现分辨率/帧数/步数。

标志：红 C + 深紫蓝 A + 浅色 C（`packaging/logo-art.png`）。

## 5. 总体架构

```
用户
 ├─ CLI (typer) ──┐
 ├─ 桌面 (pywebview + DesktopAPI) ──┤
 └─ 库调用 ────────┘
                    ▼
              Agent 循环
           (core/agent.py)
                    │
     ┌──────────────┼──────────────┐
     ▼              ▼              ▼
 LLMProvider     ToolRegistry   PermissionPolicy
 (llm/)          (tools/, MCP)  (security/)
     │
     ├─ 单后端  Anthropic / OpenAI / Ollama / …
     └─ 聚合     AggregateProvider
```

桌面不另起 HTTP 服务：JS 通过 `pywebview.api.*` 调 Python `DesktopAPI`。HTML/CSS/JS 集中在 `src/codeagent/desktop/ui.py`。

配置与数据：

| 位置 | 内容 |
|---|---|
| `~/.codeagent/settings.json` | 个性化 |
| `~/.codeagent/` 下 models / router 等 | 模型资产、自由路由规则 |
| `~/.codeagent/logs/` | 运行日志（轮转） |
| `~/.codeagent/runs/` | 指挥运行存档 |
| 项目文件夹 | 对话与附件（桌面项目体系） |

## 7. 安全与隐私

- 工具风险：`READ_ONLY` → `WRITE` → `EXECUTE` → `DESTRUCTIVE`；Shell 按命令内容再分类。  
- 默认策略：写入与执行需确认；`--yes` 或桌面「自动批准」会跳过，仅限信任环境。  
- 路径限制在工作区，防逃逸。  
- 密钥用本机指针存储，不要把 `.env` 与 `~/.codeagent` 打进安装包。  
- 条款见 `PRIVACY.md`；桌面首次启动需确认。

## 9. 构建与发版约束

- **macOS DMG**：本机 `python scripts/build_desktop.py`。  
- **Windows**：必须在 Windows 上执行同一脚本，并安装 Inno Setup 6 才能出 setup.exe。  
- **CI**：推送 `v*` 标签触发 `.github/workflows/binaries.yml`（windows-amd64、macos-amd64、macos-arm64）。  
- 版本号以 `pyproject.toml`、`src/codeagent/__init__.py`、`releases.py` 的 `latest()` 为准，三者须一致。
