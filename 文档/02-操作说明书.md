# CodeCoreAgent 操作说明书

适用版本 **0.26.0**（含自由路由、当前标志、设置页滚动）  
产品窗口名：**CodeCoreAgent**  
命令行名：`codeagent`

---

## 1. 环境准备

### 1.1 源码运行（开发或未装安装包）

需要 Python 3.10 或以上（建议 3.12）。

```bash
cd CodeCoreAgent-0.26.0    # 解压后的工程根目录
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -U pip
pip install -e ".[all,dev]"        # 或按需：.[desktop,anthropic,openai]
```

API Key（按你用的后端设置，Ollama 不需要）：

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export OPENROUTER_API_KEY="sk-or-..."
```

### 1.2 安装包运行（不装 Python）

| 平台 | 文件 | 做法 |
|---|---|---|
| macOS Apple Silicon | `codeagent-desktop-macos-arm64.dmg` | 打开 → 把 `CodeCoreAgent.app` 拖到「应用程序」 |
| Windows x64 | `*-setup.exe` 或便携 zip | 向导安装，或解压后运行 `codeagent.exe` |

首次若提示无法验证开发者：右键 App → 打开。  
本机用户数据在 `~/.codeagent`（Windows 为 `%USERPROFILE%\.codeagent`）。

## 2. 启动

```bash
codeagent desktop                 # 桌面窗口
codeagent desktop --root ~/code   # 指定默认可读写的工作区
codeagent version
codeagent changelog
```

安装包启动：打开 **CodeCoreAgent**。窗口标题与侧栏均为 CodeCoreAgent。

首次启动会弹出 **隐私条款**，须点「我已阅读并同意」才能继续。之后可在「设置 → 隐私条款」再看。

## 3. 桌面操作

### 3.1 侧栏

左侧分组：**概览**（总览、对话、指挥中心）、项目列表、自动化/定时/学习/进化、底部日志与 **设置**。

点 **设置** 展开：模型管理、自由路由、权限控制、版本说明、隐私条款、偏好设置。菜单过长时侧栏可上下滚动。

### 3.2 总览

查看版本、当前模型、技能/记忆数量、本机外部 Agent 平台。快捷入口：开始对话、指挥中心、模型管理。

### 3.3 对话（主路径）

1. 顶部选择 **项目**（对话会保存在该项目下）。  
2. **模型**下拉：  
   - **自由路由**：按「设置 → 自由路由」里的规则分发。  
   - 某个本地模型 / API / 聚合池：一直用它，规则不改道。  
   - 文生视频（Gradio）：选中后输入区下方出现分辨率、帧数、推理步数。  
3. 输入问题，回车或点发送。生成中可点 **停止**。  
4. 可加附件、调思考强度。消息可复制、导出。  
5. 「＋ 新对话」开新会话；历史在顶部下拉。

状态栏会显示当前模型；走自由路由且命中规则时，会提示「路由：任务类型 → 模型」。

### 3.4 项目

新建/切换/删除项目。对话、附件落在项目目录，不进云端。

### 3.5 指挥中心

下达一条总任务，领导拆给工人。工人名册在「偏好设置」里用 JSON 配置。本机若装着 Claude Code / Codex 等 CLI，困难任务可自动求助。运行记录在 `~/.codeagent/runs/`。

### 3.6 模型管理

三个 Tab：

- **本地模型**：局域网 Ollama 或 OpenAI 兼容地址（如 `http://192.168.x.x:11434`）。可探测、设为当前、启停（Ollama）。Gradio 地址会被识别为文生视频，不能当聊天模型加进对话池。  
- **API 模型**：Base URL + 模型名 + 可选 API Key。  
- **聚合池**：至少两个成员，策略加权 / 级联 / 投票 / 规则。

### 3.7 自由路由

与对话里的「自由路由」是同一套引擎。

1. 添加规则：任务类型、关键词（逗号分隔；空=兜底）、目标（某 mix/api/local）、优先级。  
2. **路由沙盒**：输入一句话预览会分到哪，不真正调用模型。  
3. 权重：成本、质量、本地优先（0–100）。

**生效规则**：只有当前选中「自由路由」时，发消息才会按规则改道。选死某个模型则直连。

### 3.8 偏好设置

页可上下滚动。包含：

- 外观：深色 / 浅色 / 跟随系统  
- 指挥中心默认 Provider（可写 `ollama,openrouter`）、模型、Key、Base URL、聚合策略  
- 「自动批准所有工具调用」：含写文件和执行命令，**慎用**  
- 语音回复（edge-tts）与音色  
- 个性化：称呼、语言、额外说明、主机上下文  
- 工人 JSON 名册  
- 本机外部平台探测结果  

改完点 **保存全部**。点 **还原** 放弃未保存修改。

### 3.9 权限控制

按能力设置：关 / 需确认 / 允许。例如文件写入、Shell、网络、委派。操作会留审计。

### 3.10 知识库与视频运营

- **知识库**：按说明一键布置本机 wiki 结构，在项目内沉淀资料。  
- **视频运营**：选题 → 生成 → 剪辑 → 分析；生成依赖局域网 Gradio（如 WAN `/generate_video`）。对话里选中对应视频模型也可带分辨率等参数发送。

### 3.11 其他页

日志、版本说明、技能、记忆、自动化、定时任务、自我学习、进化日志：按页内按钮操作即可。进化可设是否自动应用低风险补丁、高风险是否要审批。

## 4. 命令行操作

```bash
# 单次任务（写/执行会询问 y/n/a）
codeagent run "给这个项目补单元测试" --provider anthropic

# 多轮
codeagent chat --provider ollama --model qwen2.5-coder:7b

# 跳过全部批准（危险）
codeagent run "修复 lint" --yes

# 预算 + MCP
codeagent run "查库并出报表" --budget 100000 --mcp-config mcp.json

# 聚合：本地优先，挂了走网关
codeagent chat --provider ollama,openrouter

# 领导模式
codeagent lead "把登录页做成响应式"

# 个性化
codeagent settings show
codeagent settings set --nickname 石头 --language 中文

# 日志
codeagent logs -n 50
```

工作区默认是当前目录，桌面可用 `--root`。

## 5. 库用法（嵌入脚本）

```python
import asyncio
from codeagent import Agent, create_provider, default_tools

async def main():
    provider = create_provider("anthropic")  # 或 openai / ollama
    agent = Agent(provider=provider, tools=default_tools(root_dir="."))
    print(await agent.run("阅读 src/，用三句话总结结构"))

asyncio.run(main())
```

更多 API 见根目录 `README.md`。

## 6. 打包安装包

### 6.1 macOS（在 Mac 上）

```bash
pip install -e ".[anthropic,openai,mcp,voice,desktop,packaging]"
python packaging/make_icon.py
python scripts/build_desktop.py
```

产物：`dist/codeagent-desktop-macos-arm64.dmg`（Apple Silicon）或 `*-macos-amd64.dmg`（Intel）。

### 6.2 Windows（必须在 Windows x64）

需要 Python 3.12（勾选加入 PATH）。正式安装向导还需 [Inno Setup 6](https://jrsoftware.org/isinfo.php)。

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -U pip
pip install -e ".[anthropic,openai,mcp,voice,desktop,packaging]"
python packaging\make_icon.py
python scripts\build_desktop.py
```

产物：

- `dist\codeagent-desktop-windows-amd64-setup.exe`  
- `dist\codeagent-desktop-windows-amd64.zip`

Mac **不能**生成上述 exe。也可把工程推到 GitHub 后打 `v*` 标签，由 Actions 的 `binaries.yml` 自动打三平台包。

## 7. 常见问题

**对话里没有模型 / 只有自由路由**  
到「模型管理」加本地端点或 API，并点探测。确认地址是 `http://IP:端口`。正在跑的若是旧安装包，请换成最新 DMG。

**选了规则但不走路由**  
页眉模型须是「自由路由」，不要钉死某个模型。

**设置页滚不动**  
使用含滚动修复的构建（0.26.0 当前源码）。中间区域和左侧设置菜单都应能滚。

**Win 包在 Mac 上没有**  
到 Windows 上按第 6.2 节打包，或用 GitHub Actions。

**提示无法验证开发者（macOS）**  
右键打开；若有开发者证书可用 `python scripts/sign_macos.py` 签名公证。

**密钥与隐私**  
Key 只存在本机。不要分享 `~/.codeagent` 或把 `.env` 打进 zip。条款见 `PRIVACY.md`。
