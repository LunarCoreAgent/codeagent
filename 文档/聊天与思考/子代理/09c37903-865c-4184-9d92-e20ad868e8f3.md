## 1. 对话（chat）如何存储？

**结论：分层存储——UI 层 DOM 内存、Agent 层完整 Message 内存、项目层磁盘持久化（需激活项目）。**

### 磁盘持久化（有激活项目时）

| 路径 | 说明 |
|------|------|
| `~/.codeagent/projects.json` | 项目索引（`ProjectStore`） |
| `<项目文件夹>/conversations/<conv_id>.jsonl` | 对话事件流（程序用） |
| `<项目文件夹>/conversations/<conv_id>.md` | 可读 Markdown 版（人看） |
| `<项目文件夹>/project.json` | 项目元数据 |

关键代码：

```125:131:/Users/stone/codeagent/src/codeagent/desktop/projects.py
def append_message(project: Project, conv_id: str, role: str, text: str) -> None:
    """追加一条消息到对话（jsonl 事件流 + 同步重写 md 可读版）。"""
    d = conversation_dir(project)
    line = {"role": role, "text": text, "ts": time.strftime("%Y-%m-%d %H:%M:%S")}
    with (d / f"{conv_id}.jsonl").open("a", encoding="utf-8") as f:
        f.write(json.dumps(line, ensure_ascii=False) + "\n")
```

**持久化消息结构**（简化，非完整 `Message`）：

```python
{"role": "user" | "assistant", "text": str, "ts": "YYYY-MM-DD HH:MM:SS"}
```

### 无激活项目时

- `DesktopAPI.send()` 中 `if proj is not None` 才调用 `append_message`——**无项目则不写盘**
- UI 消息仅存在于 DOM（`#chatCol`），刷新即失

### 内存层

| 组件 | 位置 | 内容 |
|------|------|------|
| `_conv_id` | `DesktopAPI` | 当前对话 ID |
| `_conv_seed` | `DesktopAPI` | 载入历史后最近 10 条，下次 `send` 拼成文本前缀 |
| `_agent.messages` | `Agent` | 完整 `list[Message]`（含 tool_calls/tool_results） |
| `_attachments` | `DesktopAPI` | 待发送附件列表（内存） |

```19:30:/Users/stone/codeagent/src/codeagent/tools/filesystem.py
def _resolve(self, path: str) -> Path:
    candidate = Path(path)
    if not candidate.is_absolute():
        candidate = self.root_dir / candidate
    resolved = candidate.resolve()
    if self.restrict_to_root and not (
        resolved == self.root_dir or self.root_dir in resolved.parents
    ):
        raise PermissionError(
            f"Path {path!r} escapes the workspace root {str(self.root_dir)!r}"
        )
    return resolved
```

## 5. `Agent.run` 如何工作？Message 列表可序列化吗？

### 核心流程

**文件：** `/Users/stone/codeagent/src/codeagent/core/agent.py`

```194:245:/Users/stone/codeagent/src/codeagent/core/agent.py
async def run(self, task: str) -> str:
    self.messages.append(Message.user(task))
    await self._refresh_memory_context(task)
    for iteration in range(1, self.max_iterations + 1):
        ...
        response = await self.provider.complete(
            messages=self.messages,
            tools=self.tools.schemas() or None,
            system=self._system_prompt(),
        )
        self.messages.append(Message.assistant(response.content, response.tool_calls))
        if not response.wants_tool_use:
            return response.content
        results = await self._execute_tool_calls(response.tool_calls)
        self.messages.append(Message.tool(results))
```

**状态：** `self.messages: list[Message]` — 纯内存，随 `reset()` 清空。

### Message 数据结构

**文件：** `/Users/stone/codeagent/src/codeagent/core/types.py`

```37:64:/Users/stone/codeagent/src/codeagent/core/types.py
@dataclass
class Message:
    role: Role          # SYSTEM | USER | ASSISTANT | TOOL
    content: str = ""
    tool_calls: list[ToolCall] = field(default_factory=list)
    tool_results: list[ToolResult] = field(default_factory=list)

    @classmethod
    def user(cls, content: str) -> Message: ...
    @classmethod
    def assistant(cls, content: str = "", tool_calls: ...) -> Message: ...
    @classmethod
    def tool(cls, results: list[ToolResult]) -> Message: ...
```

**可序列化性：**
- `Message` 是 `@dataclass`，**理论上**可 `asdict()` 序列化
- **桌面端未做**：磁盘只存 `{role, text, ts}`，**丢弃 tool_calls/tool_results**
- 桌面 `_agent` 在同一会话内复用（默认路由），保留完整 Message；切换项目/路由/reset 会重建

### Desktop 调用链

```
send(text) → threading → _run_chat(text)
  → _provider_for_message() / _build_agent()
  → asyncio.run(agent.run(text))
  → append_message(proj, conv_id, "assistant", answer)  # 只存最终文本
  → _push("done", text=answer)
```

## 建议：把「项目」接到哪些现有接口

### `send`

- **已有：** 有激活项目时自动 `append_message`、分配 `_conv_id`
- **建议增强：**
  - 无项目时提示或自动创建默认项目（否则对话不落盘）
  - 续聊时恢复 `Agent.messages`（或至少多轮 user/assistant），而非仅 10 条文本 seed
  - 可选：把 tool 轨迹写入 jsonl（扩展 schema 为 `type: message|tool_call|tool_result`）

### `attachments`

- **现状：** `_attachments` 全局内存；`pick_attachments()` 读任意路径，与项目 root 无关
- **建议：**
  - 附件默认从 `self.root` 选（或复制到 `<project>/attachments/` 再引用）
  - 持久化附件元数据到 conversation jsonl（当前只把内容拼进 user 文本）
  - 切换项目时清空 `_attachments`

### `settings`

- **现状：** `Settings` 全局（`~/.codeagent/settings.json`），所有项目共享
- **建议：**
  - 项目级：在 `project.json` 增加 `instructions` / `context`，`_build_agent()` 时 merge：`global Settings + project overrides`
  - `settings.context` 可自动注入当前项目路径/name（`get_state()` 已有 `project` 字段）
  - 长期记忆 `memory.json` 可考虑按 `project.id` 分区（当前全局）
