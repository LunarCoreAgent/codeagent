## 2. SKILL.md Format & Parsing

### Expected frontmatter

```yaml
---
name: short-kebab-case-name
description: One sentence describing when to use this skill
---
```

Parsed by `Skill.parse()` (`skill.py:36-60`):
- Delimiter: `---` on first line, closing `---` ends frontmatter
- Fields: simple `key: value` lines (quotes stripped)
- **`name`**: from frontmatter, or parent folder name if missing (`skill.py:52`)
- **`description`**: from frontmatter, default `""`
- Extra keys → `metadata` dict (not injected)
- Unterminated frontmatter → whole file treated as body, name from dirname

### Round-trip / save layout

`SkillLibrary.save()` writes to `{directory}/{skill.name}/SKILL.md` (`skill.py:114-122`).

Evolver output format (`evolve.py:38-46`):

```
---
name: short-kebab-case-name
description: one sentence describing when to use this skill
---

# Title
Concrete, actionable instructions for the agent.
```

## 4. Adding a User-Installed Skill Pack

### Manual (documented pattern)

1. Create `~/.codeagent/skills/<pack-name>/SKILL.md` with frontmatter + body
2. Restart chat or reset agent (`DesktopAPI.reset()` clears cached agent)
3. Skill appears in desktop **技能库** page via `get_skills()` (`ui.py:2063-2069`)

Test example: `/Users/stone/codeagent/tests/test_desktop.py:472-483`

### CLI override

```bash
codeagent run "task" --skills /path/to/my-skills
codeagent run "task" --skills /path/to/my-skills --evolve   # also distill new skills
```

### Self-evolution (CLI only)

After successful run, `Agent._maybe_evolve_skill()` (`agent.py:247-256`) calls `SkillEvolver.evolve()` → `SkillLibrary.save()` to the skills directory. Same-name skills are replaced (`library.add()` keys by name, `skill.py:81-84`).

### Video-ops bootstrap (writes bundled + creates workspace)

Desktop **视频运营 → 一键布置** → `bootstrap_video_ops()` → `install_bundled_skills()` + `bootstrap_workspace()`.

### Override precedence

`load_all_skills()` order: bundled → user dir files. User `SKILL.md` with same `name` **overwrites** bundled entry.
