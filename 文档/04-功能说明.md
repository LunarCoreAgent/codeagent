# CodeCoreAgent 0.36.0 功能说明

本文按**使用者能看见的能力**写清：它是什么、从哪进、背后调什么、不能做什么。  
实现细节见 [05-代码注解.md](./05-代码注解.md)；拍片专篇见 [06-导演台与Comfy.md](./06-导演台与Comfy.md)。

产品名 **CodeCoreAgent（CCA）**。包名与命令仍是 `codeagent`。配置默认只在本机 `~/.codeagent/`。

---

## 1. 三层入口

| 入口 | 怎么开 | 用途 |
|---|---|---|
| Python 库 | `from codeagent import Agent` | 嵌进自己的脚本 |
| 命令行 | `codeagent run` / `chat` / `lead` / `desktop` | 终端任务、多轮、指挥、开窗 |
| 桌面版 | 安装包 `CodeCoreAgent.app`，或 `codeagent desktop` | 日常主界面 |

安装包路径：macOS 拖 DMG 进应用程序；Windows 须在 Windows 上编 `setup.exe`（Mac 交叉编不出 exe）。

## 2. 桌面侧栏（从左到右 / 从上到下）

### 2.1 概览

| 页 | `data-page` | 做什么 |
|---|---|---|
| 总览 | `dashboard` | 版本、当前模型、技能/记忆数、外部平台；快捷入口：对话、**导演台**、指挥中心、模型管理 |
| 对话 | `chat` | 单 Agent 聊天、停生成、附件、页眉选模型；选中文生视频模型时出现分辨率/帧数/步数 |
| **导演台** | `studio` | 企划 → 分镜 → Comfy/WAN/Hailuo/Kimi 生成 → ffmpeg 合成 → 写入发布草稿。在对话和指挥中心**之间** |
| 指挥中心 | `lead` | 领导拆命令，多工人并行，进度板与历史运行 |

### 2.2 项目

| 页 | 做什么 |
|---|---|
| 项目列表 / 新建 | 每个项目独立文件夹；对话与产物落在该目录 |
| 项目记录 | `page-project`：打开文件夹、进入对话 |

### 2.3 能力

| 页 | 做什么 |
|---|---|
| 长期记忆 | 跨会话事实，可搜可加 |
| 知识库 | Obsidian / LLM Wiki 结构；本机或 NAS；投递 inbox；对话里 `knowledge_*` 工具 |
| 视频运营 | 工作区一键布置、Gradio WAN、Comfy 地址、发布草稿（**人工点发布**） |
| 技能库 | 融合技能 / 视频技能 / 本地 SKILL.md，分页展示 |

### 2.4 系统与设置

| 页 | 做什么 |
|---|---|
| 自动化 | 工作流：工具步骤串联 |

## 3. 对话里模型会自己调用的工具（不必点选）

工作室运行时（`skills/runtime.py`）按任务和项目文件启用技能，并用 `use_skill` 加载正文。

| 工具名 | 何时用 | 注解 |
|---|---|---|
| 文件/Shell 族 | 读写改、grep、跑命令 | 写/执行默认要批准 |
| `browser` | 打开网页、登录站、点按钮 | 不是只用 `web_fetch` |
| `comfy` | 出图、跑节点图 | **不是聊天模型** |
| `video_generate` | 单段文生视频 | wan / minimax / kimi / comfy |
| `video_studio` | 整条拍片 | 导演台同一套 desk |
| `video_ops_*` | 工作区状态、流水线日志、发布草稿 | 不代点平台发布 |
| `knowledge_*` | 搜/读/投递知识库 | 库需先一键布置 |
| `use_skill` | 加载任意技能包 | 不要让用户点选技能 |

## 4. 模型怎么接

- **云**：Anthropic、OpenAI 兼容（DeepSeek、Kimi、通义、MiniMax、硅基、OpenRouter 等）。
- **本机/局域网**：Ollama `/api/tags`、任意 `/v1/models`。
- **聚合**：fallback / 加权 / 级联 / 投票。
- **自由路由**：页眉选「自由路由」后按规则走；钉死某个模型则不走规则。
- **Comfy :8188**：探测为节点图服务，列出 `diffusion_models` / `vae` / UnetLoaderGGUF（GGUF 如 MiniMax-H3）。不要当聊天补全。
- **Gradio WAN :7860**：文生视频，不是离线聊天模型。

密钥只存在本机（`~/.codeagent/` 的 secrets / models），不要打进 zip、不要提交。

## 5. 视频与发布（硬规则）

1. 工作区默认 `~/Documents/CodeCoreAgent-VideoOps`，阶段目录：`00-desk` … `05-publish`。
2. 导演台成片可「写入发布草稿」→ `05-publish/draft.json`。
3. **禁止**自动登录平台、保存平台密码、自动点「发布」。
4. 缺 ffmpeg / 工作流 JSON / 后端时必须说清楚，禁止假装已生成 MP4。

---

## 6. 权限与安全

- 风险：只读 / 写入 / 执行 / 危险。
- 桌面默认可确认；勾选自动批准会放宽。
- Shell 命令会分类；路径限制在项目根内。
- 生成目录（`video_generate` 的 `dest_dir`）必须落在视频工作区内。
