# CodeCoreAgent 运行环境与依赖手册（实测）

版本 **0.36.0**（2026-09-07）  
本文基于一次完整安装 + 全量测试 + 局域网模型联调的记录整理，供接手/部署参考。

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| Python | **3.10+**（实测 3.12.0） |
| 包管理 | `pyproject.toml`（hatchling），`pip install -e .` 或 uv |
| 测试 | pytest / pytest-asyncio（`asyncio_mode = "auto"`），目录 `tests/` |
| 用户数据 | `~/.codeagent/`（模型资产、密钥指针、对话、记忆、日志） |

## 2. 虚拟环境

仓库原有 `.venv` 指向失效路径（`/Users/stone/codeagent/`）不可用。本机实测用新建 `.venv2`：

```bash
cd <仓库>/codeagent
python3 -m venv .venv2
.venv2/bin/python -m pip install -e ".[dev]"
# 按需补装（见第 3 节）
```

`.venv2/` 已加入 `.gitignore`。

## 3. 依赖分层（pyproject 的 extra 与实测补装）

基础（`.[dev]` 即含）：`pydantic>=2`、`typer`、`rich`、`pyyaml`、`pytest`、`pytest-asyncio`、`codeagent`(editable)。

| 用途 | extra / 手动 | 实测版本 |
|---|---|---|
| OpenAI / 兼容端点 | `.[openai]` | openai==3.8.0 |
| HTTP 客户端 | `mcp` extra 或手动 | httpx==0.28.1 |
| 网页抓取 web_fetch/web_scrape | `.[scrape]` | scrapling==0.4.15、curl_cffi==0.16.3、playwright==1.62、patchright==1.62.3、browserforge==1.2.4 |
| 小智协议 xiaozhi | `.[xiaozhi]` | websockets==17.1 |

**注意**：scrapling 0.4.x 把 `AsyncFetcher/StealthyFetcher` 暴露在顶层 `scrapling.*`，不是 `scrapling.fetchers`；代码已在 `tools/web.py` 兼容两种导入路径。它还会在导入期依赖 `curl_cffi`、`playwright`、`browserforge`，需一并安装，否则运行时报"未安装"。

## 4. 局域网 / 远端 Ollama

`OllamaProvider` 接受带 `/v1` 的 base_url（会剥掉转原生 `/api/chat`），并自动回退到该端点已安装的模型（`/api/tags` 探测）。

实测端点：`http://192.168.3.20:11434/v1`，模型 `qwen3-vl:8b`（8.8B 视觉模型）。

```bash
# CLI 单任务
.venv2/bin/codeagent run --provider ollama \
  --base-url http://192.168.3.20:11434/v1 --root /tmp/cca-smoke --yes "1+1 等于几？"
```

桌面对话测试可用环境变量指向真实端点：
`CODEAGENT_OLLAMA_BASE=http://192.168.3.20:11434/v1`（fixture 支持）。
注意：该 8.8B 视觉模型单轮约 2 分钟；自动技能激活会让模型在琐碎任务上调用工具，故持久化单测使用假 provider 保证确定性。

## 5. 测试

```bash
.venv2/bin/python -m pytest tests/ -q
```

实测结果：**431 passed / 0 failed / 0 skipped**（约 51 秒；仅 6 个 lxml 弃用警告）。

修复记录（提交 `16acbc1`）：
- `desktop/api.py`：`get_harnesses()` 引用不存在的 `h.binary` → 改 `h.executable`。
- `tools/web.py`：scrapling 0.4 顶层导入兼容。
- `tests/test_desktop.py`：持久化对话测试用假 provider；fixture 支持 `CODEAGENT_OLLAMA_BASE`；`wait_for` 支持 `CODEAGENT_TEST_TIMEOUT`。
- `tests/test_harness.py`：断言改为"不存在的 binary 被过滤"（原断言假设整机无 harness，与装了 Codex CLI 的机器冲突）。

## 7. 桌面窗口

`codeagent desktop` 会真正打开 pywebview 窗口（1280x840）。`desktop --version` 是打包版 CI 冒烟用的，源码运行时 typer 不认该选项。窗口 UI 为整页 HTML（`desktop/ui.py`，约 155k 字符），服务端注入主题（深/浅/自动跟随系统）。
