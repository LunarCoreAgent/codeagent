隐私条款

CodeCoreAgent（以下简称「本软件」）是由 LunarCoreAgent 开源维护的本机桌面 Agent。默认设计为本地优先：对话、项目、配置与密钥保存在您的设备上。本条款说明我们如何处理与隐私相关的数据。

本机存储的数据

本软件会在您的用户目录下写入本地文件（通常为 ~/.codeagent/），以及您指定的项目文件夹。可能包括：应用配置、模型端点与 API 密钥（密钥单独存放且权限受限）、对话与项目记录、技能与记忆、权限审计、日志与工作流状态等。这些数据不会由本软件自动上传到 LunarCoreAgent 的服务器。

发送到第三方的数据

当您配置并选用云端或局域网大模型服务（例如 DeepSeek、通义、OpenAI 兼容网关、本机/局域网 Ollama 等）时，为完成推理，本软件会将您发起的对话内容、工具相关上下文、以及完成任务所需的代码或文件片段发送至您所指定的服务端点。该等传输受对应服务商的隐私政策与服务条款约束；本软件仅作为您配置的客户端转发请求。

遥测与广告

当前版本不包含内置遥测、广告 SDK，也不会向 LunarCoreAgent 回传使用统计。若未来引入可选诊断功能，将单独说明并默认关闭或另行征得同意。

权限与工具执行

Agent 可在您授权的范围内读写文件、执行命令或调用外部工具。请通过「权限控制」与执行前确认合理限制高风险操作。因工具执行产生的本机改动与副作用由您自行管理。

开源许可

本软件以 MIT 许可证发布。源代码与发行包不含对您个人数据的额外权利主张；本隐私条款不改变 MIT 许可证对软件本身的授权范围。

条款更新

隐私条款更新后，应用会提示您再次阅读并确认。继续使用即表示您知悉最新条款。若不同意，请停止使用并卸载本软件，同时可自行删除本地 ~/.codeagent 目录中的数据。

联系方式
